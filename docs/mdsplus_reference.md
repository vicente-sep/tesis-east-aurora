# MDSplus node reference for EAST

See Appendix B of the thesis for the consolidated mapping of diagnostic
quantities to MDSplus nodes (global plasma parameters, EFIT, ECE, XCS,
radiation, divertor, gas injection, and auxiliary heating).

**Note:** access to the MDSplus server requires being on the ASIPP local
network in Hefei. All node names in this reference were verified against
shots #143064–#143079.
