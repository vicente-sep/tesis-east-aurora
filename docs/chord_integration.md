# Chord integration for elongated flux surfaces

Derivation of the forward projection formula

    B(z) = 2 a ∫  ε(ρ) ρ / √(ρ² − ρ_min²) dρ ,  ρ_min = |z − z_ax| / (κ a)

See Appendix C of the thesis for the complete step-by-step derivation
including the numerical implementation with `numpy.trapz`.
